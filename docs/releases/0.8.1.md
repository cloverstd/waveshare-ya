优化内部 RAM 占用：网页 OTA 按需开启、会话过期后关闭，上传复用现有 OTA 工作线程。

- 开机不再创建网页 OTA 服务器；在设备上点击“网页上传”后开启十分钟会话，空闲过期或检测到 Wi-Fi 断开后释放服务器资源。
- HTTP 线程栈从 16 KiB 降至 4 KiB；固件接收、签名校验与写入复用既有 OTA 工作线程。未开启网页上传时去掉原 16 KiB 常驻 HTTP 栈分配。
- 已受理上传可以跨越会话到期时间完成，继续遵守原有传输时限；开启或请求分配失败后可重试。
- 补充 USB 会话状态与线程栈余量诊断，精简 HTTP 状态接口的栈占用。
- 修复数据站测试固定等待 10 毫秒造成的 CI 偶发失败，改为等待实际交付或提交状态。

包含 0.8.0 的命名相册与蓝牙数据站管理能力。A/B 分区、签名验证、配置回退与在线全量/增量更新合同保持不变。

已完成本地固定工具链构建、91 项主机测试与签名验证。栈分配减少量不等同于实机空闲内存实测；网页 OTA 反复开启/过期、上传跨期限、异常重试和无线并发下栈余量仍待实机验收。本次发布不会自动安装到设备。

日常升级使用签名应用 `.bin`，首次安装 ZIP 不能通过 OTA 上传。
