# Wi-Fi 与漫游（0.4.0）

目标板 ESP32-S3-Touch-AMOLED-2.16，固定 ESP-IDF 5.5.5。仅使用现有 STA、网络服务任务和电源管理；没有第二套无线栈。

## 使用

Wi-Fi 页按开关、当前连接、附近网络排列。点击当前网络查看完整名称、IP、安全类型与信号，管理自动连接和忘记网络；点击已保存的附近网络直接连接，其他加密网络要求输入密码。开放网络需确认，隐藏网络通过“其他网络”输入名称、安全类型和密码。暂不支持企业网络认证。

保存上限8个；满额时先选择替换项，仅在新网络取得IP后提交替换。密码按UTF-8字节校验，SSID最多32字节、个人网络密码8–63字节。保存失败保留连接并显示错误，断电恢复由提交记录处理。

附近网络最多16项，同SSID及相同安全类型的多个AP合并，展示最强RSSI；开放/加密网络分列。读取的原始AP记录上限64项并及时释放SDK缓存。已保存的WPA2/WPA3个人网络也允许匹配WPA3 AP，WPA3专用档案不降级到WPA2；加密档案不会匹配同名开放AP。

信号档位：≥−55dBm四格、≥−67三格、≥−75两格、更弱一格；无有效采样显示未知。当前连接每5秒采样、15秒后过期；扫描信号30秒过期。进入Wi-Fi页自动扫描，前台每15秒刷新；弹窗、连接、漫游、OTA和无线暂停时不发起页面扫描。列表保留滚动位置。

OTA期间仍由后台网络服务每5秒读取当前连接的RSSI，避免升级超过15秒后顶部信号因采样过期变为0格。此只读采样不扫描附近网络、不触发漫游或修改网络配置；读取失败不刷新采样时间，沿用原有过期规则。

## 自动连接与KVR

亮屏使用及“仅息屏”模式保持用户已开启的 Wi-Fi 可用，USB/电池供电规则一致；网页数据源是否有待同步请求、BLE 网关是否在线不会关闭前台 Wi-Fi。实际轻睡/深睡仍按省电策略暂停无线，用户唤醒或切换为“仅息屏”后恢复运行许可并自动连接。运行许可不会覆盖用户保存的 Wi-Fi/BLE 关闭开关。

保存网络包含稳定ID、安全类型、隐藏标记、自动连接开关及最近成功顺序。当前连接稳定时保持连接；断网后先尝试可见的最近成功网络，再选择其他可用网络中信号最强者。隐藏档案允许直接尝试；同一轮失败不反复重试同一项，认证失败项暂停自动尝试直至用户重试或修改凭据。单次自动尝试最多12秒、手动20秒，仍服从电源管理总预算。

启用11k(RRM)、11v(BTM)、11r(FT)，所有入口使用同一个STA配置函数，不锁BSSID/信道。实验性高级漫游模块关闭。11r的SDK支持边界是WPA2-PSK FT over-the-air；连接普通AP不要求AP支持KVR。

信号连续10秒低于−75dBm、且距上次请求至少60秒时，向支持BTM的AP发起漫游查询；若支持RRM先请求邻居列表，等待最多3秒。报告按TLV边界解析，缺失/畸形/超长时不携带候选列表。AP拒绝或不支持时保持连接。驱动报告ROAMING后应用层等待切换，15秒超时再进入正常重连；关联成功可从现有IP状态恢复，不依赖第二次GOT_IP事件。

事件回调仅投递有界队列，不进行Flash写入。扫描缓冲、事件负载、档案和GUI快照放在PSRAM；任务栈保持内部RAM。启动时保留1024字节内部优先阈值，待BSP、无线驱动初始化及显示首帧完成并取得GUI锁后，再通过SDK的heap_caps_malloc_extmem_enable(0)让普通运行时对象优先使用PSRAM，保留明确申请DMA/内部内存的驱动缓冲。扫描10秒超时会退出，避免丢失事件后一直忙碌。

## 配置与回退

保留496字节旧Config ABI。系统档案记录sys_wifi保存在运行槽的apps_a/apps_b中，业务应用不能占用该键，现有OTA逐槽复制合同沿用。凭据不进入Status、网络摘要或诊断输出。

首次启动导入v1单网络；成功选择的网络镜像到v1供旧固件使用。档案带pending、旧/新镜像摘要和镜像网络ID：先保存档案与恢复信息，再提交v1镜像，最后清除pending。启动发现提交中断时完成镜像；v1既不匹配旧摘要也不匹配新摘要，或正常记录与v1不一致时，视为旧版改配，以v1重新建立档案。旧版忘记网络后不复活此前的多个网络。

所有网络变更由网络锁→升级互斥锁→存储锁串行化。内部sys_wifi存储接口由持有升级互斥锁的网络服务调用，不递归调用会再次获取该锁的app_config_set。

## 开发诊断

USB JSON增加只读`wifi_state`（列表、RSSI、安全类型、已保存摘要、阶段、当前ID、AP的K/V能力）；不返回密码。

- `wifi_scan`：后台扫描。
- `wifi_profile`：action为connect/forget/auto，id为稳定ID；auto带enabled布尔值。
- `wifi_view`：仅请求GUI打开视图，view=1为指定保存ID详情、2为附近列表下标的密码视图、3为已保存列表；id始终必填。用于渲染检查，不直接连接网络。
- 旧`wifi`配网入口保留；可选options：低2位安全类型(0开放、1WPA2/WPA3个人、2WPA3)，位3隐藏网络，高位为替换ID左移8位。未提供options时按是否有密码推断。

实际设备、漫游及物理触摸验收见VALIDATION.md；编译成功不等于多AP漫游或长期稳定性通过。
