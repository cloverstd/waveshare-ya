# 电池统计与时间估算

适用 ESP32-S3-Touch-AMOLED-2.16。0.6.1 起提供“系统状态 → 电池使用统计”，无需新增应用或初始化第二套 PMU/I2C。尚未用真实充放电周期校准精度。

## 界面

系统状态改为并排双列卡片：左侧电池圆环显示当前电量，用 USB / 电池图标区分供电，闪电/对勾分别表示充电/已充满；右侧圆环表示本段增加或消耗的百分点，上/下箭头表示充/放电，眼睛后为预计剩余时间，循环箭头后为本段监测时长，刷新图标后为近期速率。未知估算保持“正在估算”，不编造趋势或时间。

内部 RAM 与 PSRAM、内置存储与 TF 卡分别成对显示。实心/空心芯片、存储器/卡片图形区分资源；圆环和中心百分比表示已用比例，去掉原有名称、容量长句和横向进度条。无卡、容量未知仍显示明确状态。正文继续在共同安全区内纵向滚动，进入/退出不创建额外硬件或采样任务。

- 电池放电：本段监测时长、电量消耗百分比、该段平均耗电速率、近期耗电速率、预计剩余可用时间。
- USB 正在充电：监测时长、电量增加百分比、平均/近期充电速率、预计充满还需多久。
- 尚无足够样本显示“正在估算”；电量未知、无电池、USB 未充电或状态不一致时不显示时间。
- 充电电量连续20分钟无增长显示“电量暂无增长，暂不可估算”。此提示不诊断充电器故障；恢复增长后重新计算。
- 电量显示100%但PMU仍未报告充电完成，显示“等待充满确认”。只有USB供电、充电完成且未充放电时显示“已充满”，诊断剩余时间为0。

统计单位为电量**百分点**和百分点/小时；例如从80%降至75%，消耗5个百分点。并非mA、mAh或Wh测量。时间按5分钟向上取整，最少显示约5分钟，避免整数电量产生秒级精度的错觉。

## 采样与边界

沿用服务线程的PMU采样，正常运行每秒一次；电源协调器暂停普通服务时每分钟一次。I2C读操作在GUI锁外进行，GUI只消费状态快照。使用约1.1KiB的固定RAM跟踪器，每2分钟保留一点，最近最多2小时；不增加任务、网络请求或Flash写入。

至少连续监测5分钟且电量同向改变2个百分点后才显示近期速率和时间。短于该窗口、不足2个百分点或超出7天的估计保持“正在估算”，不会因电量不动显示无限续航。数据不连续超过90秒、时间倒退/重复、充放电/USB状态变化、单次电量跳变超过3个百分点或逆向修正超过1个百分点都会开始新监测段。1个百分点的反向抖动不累计额外消耗。

本段消耗与平均速率从当前连续监测段开始计算；剩余时间使用最近最多2小时速率，随负载变化重新计算。亮屏、息屏和无线活动不单独标定，因此数字表示近期使用方式继续时的近似时间，并不保证未来改变亮度、网络或休眠模式后仍有相同续航。电量0%也不代表精确的硬件关机点。

重启、OTA或深睡唤醒后重新积累样本。深睡期间不保留监测历史；不把未观察到的充放电算进统计。普通轻睡/显示暂停期间保持稀疏采样。监测不修改充电电流、电压、电源轨、保护策略、持久配置、A/B分区或eFuse。

## 充电后段修正

估算使用近期电量增长速度，并加入显式的、**未经实机校准的经验权重**：0–80%、80–90%、90–95%、95–100%各个百分点的充电工作量权重为1、1.5、2、3。用当前窗口实际增加的加权工作量/经过时间拟合速度，再推算剩余加权工作量。窗口跨区间时不会直接把低电量区间的速度线性延伸到100%；观察到的变慢会继续修正结果。

这些权重不是AXP2101数据手册给出的时间或当前电池实测参数，也不读取充电电流限值来冒充实际电流。不同电池、供电、温度与设备负载都可能带来较大偏差，需要真实完整周期记录后再调整。硬件归属见[Waveshare该板官方说明](https://docs.waveshare.com/ESP32-S3-Touch-AMOLED-2.16)，采样能力以仓库固定的XPowersLib和`board.cpp`为准。

## USB / BLE 诊断

现有`status`响应新增`battery_stats`对象，USB和BLE字段一致，不改变原有字段含义。

| 字段 | 含义 |
|---|---|
| mode | unknown / discharging / charging / usb_idle / full |
| phase | unavailable / learning / ready / no_progress / confirming_full / full |
| session_seconds | 本段连续监测秒数 |
| change_percent | 本段同向电量改变的百分点数 |
| session_percent_per_hour | 本段平均速率，样本不足时null |
| recent_seconds | 近期窗口秒数，不超过7200 |
| recent_percent_per_hour | 近期实际百分点/小时，样本不足或充电停滞时null |
| remaining_minutes | 预计剩余可用/充满分钟，未知为null；0仅表示PMU确认充满 |

USB另提供`battery_present`、原始`battery_full`和`battery_sample_age_ms`。原始full位可能在拔USB后仍保留，不能单独用它判定当前充满。采样年龄供诊断使用，正常显示暂停期最长约60秒。

## 验证

`tests/battery_estimator_test.cpp`直接重放固件使用的算法，覆盖恒定耗电、近期负载变化和环形窗口回绕、整数电量抖动/跳变、暂停/失效、充电区间减速、停滞后恢复、PMU充满确认及长运行时长。主机回放和编译不能代替真实电池精度验收，当前构建记录见[VALIDATION.md](VALIDATION.md)。
