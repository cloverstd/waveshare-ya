# 日志应用

桌面的“日志”显示系统 ESP-IDF 运行日志。记录在应用关闭、息屏时仍继续；页面每秒刷新一次，最新条目在上。顶部单行工具栏包含级别下拉、记录数/覆盖数、暂停或恢复刷新图标及清空图标；丢弃数非零时追加显示，过长计数在本行省略。其余高度用于滚动日志。滑动查看旧记录会自动暂停刷新，也可点击暂停图标冻结显示，点击刷新图标立即恢复刷新。暂停不停止后台记录。垃圾桶图标只清空本次运行的日志，不影响通知历史或级别设置。

记录级别默认 **WRN（Warning）**，包含 Warning 与 Error。下拉仅显示英文缩写：OFF、ERR、WRN、INF、DBG、VRB，依次对应关闭、Error、Warning、Info、Debug、Verbose；所选级别及更严重的日志会被记录。改变级别会同时调整系统 ESP-IDF 日志输出，原串口输出目的地保留。关闭不删除已有记录，已记录的内容也不会随新级别重新筛选。

日志只保留本次开机最近100条，单条最多255字节，UTF-8尾部安全截断；满后覆盖最早记录。界面显示记录数、覆盖数、争用丢弃数。记录和显示快照使用PSRAM，日志钩子使用固定栈缓冲、非阻塞互斥，不执行GUI、网络或Flash操作。高频输出时允许有界丢弃，保留串口输出。日志不写入Flash，重启/深睡后清空；默认级别恢复前的启动早期只记录Warning及以上。

级别以schema 1、单字节0–5保存于应用配置`logs`，由`setting_async("log_level", value)`交给现有服务任务提交NVS；仅保存成功后应用新级别，失败恢复原控件值。通过`app_config_get/set`遵守现有A/B配置复制及回退规则，不改变旧Config ABI。无记录或记录无效时使用Warning。编译保留Verbose上限，使Debug/Verbose可以在运行期选择；库明确移除或单独限制的日志无法补回。

采集使用固定ESP-IDF 5.5.5 Log V1的`esp_log_set_vprintf`输出片段，按任务拼接完整行，保留级别、开机毫秒时间和tag，移除终端颜色。直接printf、ROM/中断/缓存关闭日志、bootloader以及app_main之前的输出不在此应用的采集范围。动态中文日志仍受当前字体子集限制。

应用经注册表创建，页面使用共享安全区、下拉列表及异步设置完成结果；退出时释放显示快照与对象引用，不增加线程、订阅或计时器。诊断页面ID14；`{"op":"logs"}`读取最早到最新的有界记录与计数，`{"op":"logs_clear"}`清空；`status.log_level`返回当前级别。诊断`set`沿用`log_level`键；诊断输出不递归进入采集。

已有构建缓存仍可能保留旧Info默认及编译上限。使用`tools/build_release.sh 0.5.0`自动更新其日志配置，或为新构建目录加载`sdkconfig.defaults`。编译断言会拒绝与采集协议或级别范围不一致的配置。

## 当前开发版修正与蓝牙导出

Wi-Fi 日志可能将前缀、正文、换行分多次调用输出；采集现按任务使用8个固定拼接槽，同任务拼接后按换行提交，未结束内容最长1秒后提交。支持 `E (123) wifi:` 与 `E(123)wifi:` 前缀，避免正文被级别过滤丢弃。不同任务交错不混行；超长内容仍安全截断至255字节，串口原始输出保留。日志条目新增递增 sequence，清空不复用；boot 标识区分重启。

日志页新增上传图标，异步发送当前日志快照；最后一批收到网页 ACK 后才提示完成。网页支持分页读取、主动订阅及下载，详情见 [COMPANION.md](COMPANION.md)。仅实时订阅不阻止休眠；有界主动发送最长2分钟。日志采集钩子始终不执行网络、GUI、存储或阻塞等待。
