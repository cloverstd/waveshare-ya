## 0.5.0 电池供电 Wi-Fi 运行许可修正（2026-10-30，北京时间）

根因：旧 `power_tick()` 在亮屏、电池供电且存在数据计划时使用 `data_needs_wifi()` 决定无线运行许可。该值只表示数据服务当前是否需要 Wi-Fi；没有待同步请求、未配置 HTTP 数据端点或已有 BLE 网关时会为 false，导致系统主动停止 STA，手动连接也被 `runtime_allowed` 拦截。USB 分支始终许可，因此插回 USB 会掩盖问题。此为源码定位，实际拔线复现尚待对应实机条件。
